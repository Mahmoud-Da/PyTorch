*** 200. What Is Experiment Tracking and Why Track Experiments ***
## Lecture Summary: Experiment Tracking in Machine Learning

### 1. **What is Experiment Tracking?**

* **Definition**: The process of keeping a structured record of your modeling experiments to determine which ones perform best.
* **Purpose**: Helps identify what works and what doesn’t, especially as the number of models increases.

### 2. **Why Is It Important?**

* As more models are created (e.g., `model_0`, `model_1`, `model_2_v3`, etc.), tracking manually becomes chaotic.
* Helps answer:

  * Which model performs best?
  * What changes led to improvements or regressions?
  * What should be repeated or avoided in future experiments?

### 5. **Tracking Methods**

* **Basic Tracking**:

  * Python dictionaries
  * CSV files
  * Printouts
* **Intermediate to Advanced Tools**:

  * **TensorBoard** (integrated with PyTorch)
  * **Weights & Biases (W\&B)**: Third-party tool with powerful UI

  * **Other Tools**: Search "machine learning experiment tracking" for more

## **2.1: Creating Data Loaders with Manual Transforms**

### **Why Transforms Are Important**

* Pre-trained models expect data in a specific format (size, range, normalization).
* Most are trained on **ImageNet**, so replicating its preprocessing ensures optimal performance.
* Mismatched preprocessing can lead to **performance degradation**.

---

## **Setting Up Paths**

-------------------code----------------------
train_dir = image_path / "train"
test_dir = image_path / "test"
-------------------code----------------------

---

## **Manual Transform Pipeline**

### **Normalization Values (ImageNet)**

-------------------code----------------------
normalize = transforms.Normalize(
    mean=[0.485, 0.456, 0.406],
    std=[0.229, 0.224, 0.225]
)
-------------------code----------------------

### **Transform Composition**

-------------------code----------------------
manual_transforms = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    normalize
])
-------------------code----------------------

* **Resize**: Ensures input images are at least 224x224 (required by most ImageNet models).
* **ToTensor**: Converts images to tensors in range \[0, 1].
* **Normalize**: Matches ImageNet data distribution.

*** 204. Turning Our Data into DataLoaders Using Automatic Transforms ***
## **Lecture Summary: Creating Data Loaders with Automatically Created Transforms**

---

### **Context**

* This builds upon the previous video, where we created data loaders using **manual transforms**.
* The goal now is to create **data loaders using automatic transforms** derived directly from model weights.

---

## **Objective**

* Apply **automatically generated transforms** to ensure custom data is processed in the **same format** as the data used to train **pre-trained models**.
* This ensures optimal performance when using transfer learning.

---

## **Automatic Transforms via TorchVision (v0.13+)**

### **TorchVision Model Weights API**

* TorchVision now supports a **multi-weight API**.
* Each pre-trained model (e.g., EfficientNet, ResNet) has associated weight classes.
* These weight classes contain a `.transforms()` method that returns the **appropriate preprocessing pipeline**.

---

### **Steps to Create Automatic Transforms**

#### 1. **Choose the Model and Import Weights**

-------------------code----------------------
from torchvision.models import EfficientNet_B0_Weights

weights = EfficientNet_B0_Weights.DEFAULT
-------------------code----------------------

* `.DEFAULT` refers to the best available pre-trained weights for that model.

#### 2. **Get the Transforms**

-------------------code----------------------
automatic_transforms = weights.transforms()
-------------------code----------------------

* This creates a transformation pipeline matching what the pre-trained model expects.

---

## **Creating Data Loaders with Automatic Transforms**

#### 3. **Pass Transforms to Data Loader Function**

Assuming the helper function `create_dataloaders()` is already defined:

-------------------code----------------------
train_dataloader, test_dataloader, class_names = create_dataloaders(
    train_dir=train_dir,
    test_dir=test_dir,
    transform=automatic_transforms,
    batch_size=32
)
-------------------code----------------------

#### 4. **Print to Verify**

-------------------code----------------------
print(f"Automatically created transforms:\n{automatic_transforms}")
-------------------code----------------------

---

## **Comparison to Manual Transforms**

| Feature         | Manual Transforms                  | Automatic Transforms                   |
| --------------- | ---------------------------------- | -------------------------------------- |
| **Flexibility** | High – user-defined                | Limited to model’s training pipeline   |
| **Risk**        | High – risk of mismatching formats | Low – guaranteed compatibility         |
| **Performance** | Depends on correctness of setup    | Optimized for target pre-trained model |

* Manual transforms allow more data augmentation/customization.
* Automatic transforms are safer for direct use with transfer learning models.

*** 205. Preparing a Pretrained Model for Our Own Problem ***
## Lecture Notes: Using Pre-trained Models in PyTorch (EfficientNet Example)

### 1. **Pre-trained Model Overview**

* A **pre-trained model** uses learned parameters from a large dataset (e.g., ImageNet).
* When using pre-trained models:

  * **Base layers are frozen** to retain learned features.
  * The **classifier head** is replaced to suit your specific problem (e.g., number of output classes).

---

### 2. **Old vs New API in `torchvision`**

#### Old Way (Before `torchvision 0.13`)

-------------------code----------------------
model = torchvision.models.efficientnet_b0(pretrained=True)
-------------------code----------------------

* This raises a **deprecation warning**:

  * `pretrained=True` is deprecated since `0.13`
  * Will be **removed in `0.15`**
  * Use the `weights` argument instead.

#### New Way (From `torchvision 0.13` onwards)

-------------------code----------------------
from torchvision.models import efficientnet_b0, EfficientNet_B0_Weights

weights = EfficientNet_B0_Weights.DEFAULT
model = efficientnet_b0(weights=weights)
-------------------code----------------------

* `weights=EfficientNet_B0_Weights.DEFAULT` uses the **best available weights**.
* Other weight options are documented on the official PyTorch site.

---

### 3. **Freezing Base Layers**

To **freeze** the model's pre-trained base:

-------------------code----------------------
for param in model.parameters():
    param.requires_grad = False
-------------------code----------------------

* Disables gradient computation for these parameters.
* Prevents updates during training, making them **unchangeable**.

---

### 4. **Modifying the Classifier Head**

#### Why?

* Pre-trained models are typically trained for 1000 classes.
* You need to replace the final layer for your specific task (e.g., 3-class classification).

#### How?

-------------------code----------------------
from torch import nn

model.classifier = nn.Sequential(
    nn.Dropout(p=0.2, inplace=True),
    nn.Linear(in_features=1280, out_features=3)  # Replace 3 with len(class_names)
)
-------------------code----------------------

* `1280` is the feature vector size of EfficientNet-B0.
* `out_features` should match the number of target classes.

---

### 5. **Device Setup and Reproducibility**

* **Send model to device** (`cpu` or `cuda`) after modifying the classifier:

-------------------code----------------------
model.to(device)
-------------------code----------------------

* **Set random seed** before creating new layers to ensure reproducibility.

---

### 6. **Model Summary**

Use `torchinfo` to inspect the model:

-------------------code----------------------
from torchinfo import summary

summary(
    model, 
    input_size=(32, 3, 224, 224),  # Batch size = 32, RGB image 224x224
    col_names=["input_size", "output_size", "num_params", "trainable"],
    col_width=20,
    row_settings=["var_names"]
)
-------------------code----------------------

* Displays:

  * Input/output shape per layer
  * Number of parameters
  * Whether each layer is trainable
* Shows that only the classifier is **trainable**, resulting in faster training.
