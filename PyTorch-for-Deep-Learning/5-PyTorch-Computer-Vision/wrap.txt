*** 100. What Is a Computer Vision Problem and What We Are Going to Cover ***
## **Introduction to Computer Vision**

### **What is a Computer Vision Problem?**

* A broad field—if a human can *see* something, it can likely be turned into a computer vision problem.
* Involves teaching machines to interpret and understand visual data (images or videos).

---

## **Examples of Computer Vision Problems**

### **1. Binary Classification**

* **Task**: Decide between two classes (e.g., *steak* vs. *pizza*).
* **Approach**: A machine learning model takes in image pixels and learns patterns that distinguish the two.
* **Learning**: The model is not explicitly told what a steak or pizza is—it learns from examples.

### **2. Multiclass Classification**

* **Task**: Identify an image from three or more categories (e.g., *sushi*, *steak*, *pizza*).
* **Application Example**: Nutrafol app

  * Upload an image of food.
  * The model classifies the image as one of 100 possible food items (e.g., chicken wings, apple, etc.).
  * Also detects whether an image is food or not.

---

## **3. Object Detection**

* **Task**: Locate specific objects within an image.
* **Example**: Identifying a car from a security camera video.

  * Useful for cases like identifying hit-and-run vehicles.
* **Goal**: Find where an object appears in an image and possibly track it.

---

## **4. Image Segmentation**

* **Task**: Divide an image into multiple meaningful parts.
* **Example**: Apple’s computational photography

  * Segmenting image parts: skin, hair, background, etc.
  * Used to enhance different regions individually.
* **On-Device**: Much of this processing happens directly on mobile devices.

---

## **5. Advanced Use Case: Tesla Autopilot**

* **Application**: Self-driving cars using computer vision.
* **Setup**:

  * Each Tesla car is equipped with 8 cameras.
  * These cameras feed data into neural networks.
  * The network transforms visual input into vectors (numerical representations).
* **Purpose**: Helps the car perceive its environment and make driving decisions.
* **Software**: Tesla uses PyTorch and custom hardware like the Dojo chip.

---

## **General Applications of Computer Vision**

* Widely used across various industries: security, medical imaging, retail, automotive, etc.
* Many resources available to explore real-world use cases.

*** 101. Computer Vision Input and Output Shapes ***
# **Lecture Notes: Introduction to Computer Vision with PyTorch**

## **1. Overview**

* **Computer Vision (CV)**: Any problem involving visual data (e.g., images, video) can potentially be transformed into a CV problem.
* We'll focus on building **machine learning models**, especially with **PyTorch**, for computer vision tasks.

---

## **2. Inputs & Outputs in a CV Problem**

### **Example: Multi-class Classification (Food Images)**

* **Goal**: Identify images of food (e.g., sushi, steak, pizza).
* **Input**: Colored images with dimensions

  * Width = 224
  * Height = 224
  * Channels = 3 (Red, Green, Blue – RGB)

### **Why 3 Channels?**

* Digital images often use 24-bit RGB, assigning values to red, green, and blue pixels.
* Each pixel is represented by 3 values: `[R, G, B]`.

### **Numerical Representation**

* Images are converted into **tensors**: multi-dimensional arrays.
* Tensor shape: **(Batch size, Height, Width, Channels)** or **(Batch size, Channels, Height, Width)**

---

## **3. Model Outputs**

* Model predicts **class probabilities** for each category.
* Example: For a 3-class classification:

  * Output: `[0.1, 0.81, 0.09]` → highest score = class prediction.
* Output shape corresponds to the number of classes.

  * E.g., 3 classes → output shape = `[3]`
  * E.g., 100 classes → output shape = `[100]`

---

## **4. Improving Model Performance**

* Show the model more images (data) to enhance pattern recognition.
* The more diverse and larger the dataset, the better generalization on unseen images.

---

## **5. General Pattern Across CV Problems**

* Encode data numerically.
* Use a suitable ML model (e.g., for classification, detection, or segmentation).
* Ensure **input and output shapes** match the problem.

---

## **6. Model Architectures**

* **CNN (Convolutional Neural Network)**: Most common for image data.
* **Transformers**: Also perform well on vision tasks (e.g., Vision Transformers – ViTs), though CNNs remain a strong baseline.
* We'll focus on **CNNs** for now.

---

## **7. Input Tensor Shapes in Practice**

* Common input tensor shape:

  * **(Batch size, Channels, Height, Width)** → e.g., `(32, 3, 224, 224)`

    * `32`: batch size
    * `3`: color channels (RGB)
    * `224 x 224`: image dimensions
* Higher resolution (e.g., 512x512) = more data, more compute
* Batch size depends on model & hardware (e.g., 32, 64, 128)

---

## **8. Grayscale Images Example (Fashion Items)**

* Dataset: Grayscale images of clothing items (28x28 pixels)
* Follows the same process:

  * Encode data
  * Feed to ML model
  * Predict class
* Output: One of 10 clothing item classes (e.g., shirt, pants, boots)

---

## **9. Image Tensor Representations**

* Two common formats:

  1. **Channels last (NHWC)**: `(Batch, Height, Width, Channels)`
  2. **Channels first (NCHW)**: `(Batch, Channels, Height, Width)`
* PyTorch defaults to **channels first**
* Be mindful of format mismatches — incorrect order can lead to errors
* Efficient formats and library conventions vary

---

## **10. PyTorch Workflow Recap**

1. **Prepare the data**

   * Use `torchvision.transforms` to convert images into tensors
   * Use `torch.utils.data.Dataset` and `DataLoader`
2. **Build the model**

   * Custom or pre-trained models using `torch.nn` and `torchvision.models`
3. **Define optimizer and loss function**

   * Standard: `torch.optim`, `torch.nn.functional`, etc.
4. **Evaluate the model**

   * Use `torchmetrics` or write custom evaluation functions
5. **Experiment and improve**

   * Try different models, architectures, hyperparameters
6. **Save & reload**

   * Use `torch.save()` and `torch.load()` for model persistence

*** 102. What Is a Convolutional Neural Network (CNN) ***
# **Lecture Notes: Introduction to Convolutional Neural Networks (CNNs)**

## **Recap of Previous Video**

* Discussed computer vision problems, input/output shapes.
* Introduced the concept of **Convolutional Neural Networks (CNNs)** as effective models for recognizing patterns in images.

---

## **What is a Convolutional Neural Network (CNN)?**

* CNN: A type of deep learning architecture designed specifically for image data.
* Abbreviation “CNN” refers to *Convolutional Neural Network*, **not** the news network.

### **Learning Resources**

* Many good guides available online (e.g., Code Basics).
* Best resource = the one **you understand the best**.
* Images and diagrams can help, but this course focuses on **code-first learning**.

---

## **Typical CNN Architecture**

### **Components**

1. **Input Layer**

   * Takes in image data with a defined number of channels (e.g., RGB).
   * Important: input and output **shapes must align** throughout the model.

2. **Convolutional Layer**

   * Applies mathematical operations across the image using filters (kernels).
   * Performs a **sliding window operation** to extract features.
   * Formula:

     $$
     \text{Output} = \text{Bias} + \sum (\text{Weight Matrix} \times \text{Input})
     $$
   * Torch module: `torch.nn.Conv2d`

3. **Activation Function**

   * Applies non-linear transformations (e.g., ReLU).
   * Helps model non-linear relationships in data.

4. **Pooling Layer**

   * Reduces spatial size (height & width) of feature maps.
   * Helps with computation efficiency and overfitting reduction.
   * Common methods: Max Pooling, Average Pooling.

5. **Output Layer**

   * Converts the processed features into predictions.
   * Often a `Linear` (fully connected) layer with number of outputs = number of classes.

---

## **Workflow of a CNN in PyTorch**

* The model is usually defined using `nn.Sequential` or custom `nn.Module`.
* Forward pass:
  Input images → Conv layers → Activation → Pooling → Output → Prediction
* Example: Model predicts class labels from image inputs.

---

## **Important Note**

* **Infinite Variations** of CNNs exist.
* The structure shown is **just one typical configuration**.
* As you progress, you'll learn to build or use more **complex or pre-trained models** (e.g., in Transfer Learning).
