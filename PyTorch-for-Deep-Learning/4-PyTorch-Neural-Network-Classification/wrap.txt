*** 68. Introduction to Machine Learning Classification With PyTorch ***
### **Classification in Machine Learning**

#### **1. What is a Classification Problem?**
- Classification is one of the main types of problems in machine learning.
- It involves predicting a label or category for a given input.
- Common in everyday scenarios, often powered by machine learning models.

---

### **2. Real-World Examples**

- **Spam Detection**:
  - Input: An email message.
  - Output: "Spam" or "Not Spam".
  - This is an example of **Binary Classification** (only two possible classes).

- **Food Image Recognition**:
  - Input: A photo of food.
  - Output: "Sushi", "Steak", or "Pizza".
  - This is **Multi-class Classification** (more than two classes).

- **Wikipedia Tagging**:
  - Input: A Wikipedia article.
  - Output: Multiple relevant tags (e.g., "Deep Learning", "Artificial Intelligence").
  - This is **Multi-label Classification** (each input can have multiple labels).

---

### **3. Types of Classification Problems**

- **Binary Classification**:
  - Two possible output classes (e.g., spam vs. not spam, cat vs. dog).
  - Example: Distinguishing between dog and cat images.

- **Multi-class Classification**:
  - More than two classes.
  - Each input is assigned to one and only one class.
  - Example: Recognizing food types like sushi, steak, or pizza.
  - Large-scale example: ImageNet dataset with 1,000 classes.

- **Multi-label Classification**:
  - Inputs can belong to multiple classes simultaneously.
  - Example: Assigning multiple topic tags to a Wikipedia article.

---

### **4. Key Concepts to Be Covered**

- **Architecture of a Neural Network Classification Model**
  - How the model is structured to handle classification tasks.

- **Input and Output Shapes**
  - Inputs are typically numerical and structured in tensors.
  - Understanding the shape is crucial for building models.

- **Features and Labels**
  - Inputs = Features (e.g., image pixels, words)
  - Outputs = Labels (e.g., "spam", "not spam")

- **Creating Custom Data**
  - Generating and manipulating datasets to train models.

- **Model Training**
  - Using loss functions and optimizers specifically for classification.
  - Building training and testing loops.

- **Saving and Loading Models**
  - Persisting models for reuse without retraining.

- **Nonlinear Parity**
  - Understanding how non-linear decision boundaries work compared to linear ones.

- **Evaluation Methods**
  - Various metrics and tools to evaluate the performance of classification models.

*** 69. Classification Problem Example: Input and Output Shapes ***
## Lecture Summary: Classification Inputs and Outputs

### Overview
In this lecture, we moved from a general understanding of classification problems to exploring the actual **inputs and outputs** involved in a classification task. The example used throughout is an app called **FoodVision**, designed to classify food photos.

---

### Classification Workflow
1. **Input**  
   - Raw data: Images (e.g., sushi, steak, pizza photos)
   - Must be numerically encoded for machine learning algorithms to process.
   - Common encoding for images:
     - Shape: **(width, height, color_channels)**  
     - Example: **(224, 224, 3)**  
       - 224 width, 224 height, 3 color channels (RGB)

2. **Machine Learning Algorithm**
   - A model (e.g., neural network) that processes the encoded input.
   - Can be custom-built (e.g., with PyTorch) or a pre-trained model (e.g., in transfer learning).

3. **Output**
   - Model predicts **probabilities** for each class (e.g., 0.9 for pizza, 0.05 for sushi, 0.05 for steak).
   - These are **not discrete labels** but **prediction probabilities**.
   - Final prediction is the class with the highest probability.

---

### Types of Classification Illustrated
- **Single-label, Multiclass Classification**  
  - One label per input image (e.g., either sushi, steak, or pizza).

---

### Input Encoding Details
- Image representation: Pixel values across 3 color channels (R, G, B).
- Image tensor shape example:  
  - **(batch_size, color_channels, width, height)**  
  - Example: **(32, 3, 224, 224)**  
    - 32 images per batch (common batch size).
    - 3 color channels.
    - 224 x 224 image resolution.

> Note: PyTorch uses the shape **(C, W, H)** (channels-first), but other libraries (like TensorFlow) may use **(W, H, C)**.

---

### Batch Size
- Common batch size: **32**
- Helps manage memory and computational limits.
- Based on community recommendations and performance balance.

---

### Output Shape
- Depends on the number of classes.
  - For 3 food classes (sushi, steak, pizza): output shape is **(batch_size, 3)**
  - For binary classification: output could be **(batch_size, 1)** or **(batch_size, 2)**

---

### Key Takeaways
- Inputs must be **numerically encoded** (tensors of pixel values).
- Outputs are **prediction probabilities** per class.
- Tensor shapes:
  - **Inputs**: `(batch_size, channels, width, height)`
  - **Outputs**: `(batch_size, number_of_classes)`
- The number of output classes is determined by the specific classification problem.
- Machine learning improves by iterating: add more data, retrain, and refine predictions.
