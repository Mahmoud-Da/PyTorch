*** 134. What Is a Custom Dataset and What We Are Going to Cover ***
## **Lecture Notes: Custom Datasets in PyTorch**

### **1. Introduction to Custom Datasets**

* So far, various PyTorch models have been built using standard datasets (e.g., FashionMNIST).
* The question arises: *Can PyTorch models be built using your own custom data?*
* **Answer:** Yes, but the data must go through preprocessing steps to make it compatible with PyTorch.

---

### **2. PyTorch Domain Libraries**

PyTorch offers specialized libraries for different types of data:

* **torchvision**: For image (vision) data (e.g., classifying photos of food).
* **torchtext**: For natural language/text data (e.g., sentiment analysis).
* **torchaudio**: For audio data (e.g., identifying music like Shazam).
* **torchrec**: For recommendation systems (e.g., Netflix home page).
* **torchdata** (in beta as of April 2022): General data loading utilities.

Each domain library contains:

* Prebuilt datasets.
* Functions to load and preprocess your own custom data.

---

### **3. Example Use Case: Building a Custom Dataset**

#### Goal:

Build an image classification model named **FoodVision Mini**.

#### Dataset:

* Custom image dataset including: **pizza, sushi, and steak**.
* Based on the **Food101** dataset.

#### Objective:

* Load images into PyTorch.
* Train a model to classify images as either pizza, sushi, or steak.
* Use this model in a practical app (e.g., **NutriFact App**).

---

### **4. The PyTorch Workflow**

To work with custom data, we will follow a familiar PyTorch workflow:

1. **Load the custom dataset** using prebuilt or custom functions.
2. **Transform and visualize** the data.
3. **Prepare the data** for modeling (e.g., using transformations).
4. **Build and train** the model:

   * Define model architecture.
   * Choose loss function and optimizer.
   * Write a training loop.
   * Evaluate performance.
5. **Improve** the model through experimentation (e.g., data augmentation).
6. **Make predictions** on new, unseen custom data.
7. **Save and reload** the trained model.

---

*** 136. Downloading a Custom Dataset of Pizza, Steak and Sushi Images ***
## **PyTorch Custom Datasets – Part 2: Obtaining the Dataset**

### **Objective**

Prepare a smaller custom dataset (Pizza, Steak, Sushi) derived from the **Food101 dataset** to practice working with custom data in PyTorch.

---

### **1. Overview:**

* The full **Food101** dataset contains:

  * **101 food categories**
  * **101,000 images**
  * Each class has:

    * **750 training images**
    * **250 test images**
* For this course, a **smaller subset** was created:

  * **3 categories**: `pizza`, `steak`, `sushi`
  * **10% of original data**: \~75 train / 25 test images per class

**Reason for Subsetting**:
Smaller datasets allow **faster experimentation** and **faster model training**. Always begin with a small version of the data and scale up as needed.

---

### **2. Dataset Structure**

Created in **image classification style**:

-------------------code----------------------
pizza_steak_sushi/
│
├── train/
│   ├── pizza/
│   ├── steak/
│   └── sushi/
│
└── test/
    ├── pizza/
    ├── steak/
    └── sushi/
-------------------code----------------------

Creation process documented in the `extras` folder:
**Extras → Custom Data Creation → pizza\_steak\_sushi notebook**

---

### **3. Downloading the Dataset**

#### **Libraries Used**

-------------------code----------------------
import requests
import zipfile
from pathlib import Path
-------------------code----------------------

#### **Set Paths**

-------------------code----------------------
data_path = Path("data")
image_path = data_path / "pizza_steak_sushi"
-------------------code----------------------

#### **Check for Existing Data**

-------------------code----------------------
if image_path.is_dir():
    print(f"[INFO] {image_path} directory exists. Skipping download.")
else:
    print(f"[INFO] {image_path} does not exist. Creating directory...")
    image_path.mkdir(parents=True, exist_ok=True)
-------------------code----------------------

#### **Download the Dataset**

Use the **raw** URL from GitHub (important: must use `raw.githubusercontent.com`, not `github.com/blob`):

-------------------code----------------------
url = "https://raw.githubusercontent.com/mrdbourke/pytorch-deep-learning/main/data/pizza_steak_sushi.zip"
target_file = data_path / "pizza_steak_sushi.zip"

with open(target_file, "wb") as f:
    print("[INFO] Downloading pizza_steak_sushi dataset...")
    request = requests.get(url)
    f.write(request.content)
-------------------code----------------------

#### **Unzip the Dataset**

-------------------code----------------------
with zipfile.ZipFile(target_file, "r") as zip_ref:
    print("[INFO] Unzipping dataset...")
    zip_ref.extractall(image_path)
-------------------code----------------------

#### **Final Structure Check**

Once unzipped, you should see:

-------------------code----------------------
data/
└── pizza_steak_sushi/
    ├── train/
    │   ├── pizza/
    │   ├── steak/
    │   └── sushi/
    └── test/
        ├── pizza/
        ├── steak/
        └── sushi/
-------------------code----------------------

---

### **4. Key Takeaways**

* Start small when working on ML projects.
* Use reproducible scripts to download and set up datasets.
* Always verify dataset structure before loading into PyTorch.
* The same setup applies to other custom datasets and domains (text, audio, etc.).

### 3. **Walking Through Directories**

* Python’s `os.walk()` is used to recursively explore dataset directories.
* The function returns a tuple:

  -------------------code----------------------
  (dirpath, dirnames, filenames)
  -------------------code----------------------
* This is useful for:

  * Counting the number of images per class
  * Verifying the directory structure

* `data/pizza_steak_sushi/test/steak` contains 19 test images

  * 78 pizza images
  * 75 steak images
  * 72 sushi images

---

### 4. **Dataset Preparation**

* Setting up dataset paths:

  -------------------code----------------------
  train_dir = "path/to/train"
  test_dir = "path/to/test"
  -------------------code----------------------
* This mirrors standard format expected by PyTorch's `ImageFolder`:

  * Root directory contains subfolders for each class
  * Class name = folder name
  * Images for each class go inside corresponding folders

---

### 5. **Why Use This Format?**

* PyTorch's `torchvision.datasets.ImageFolder` expects this format by default.
* Advantages:

  * Easy to load with built-in tools
  * Simple structure
  * Easily scalable (e.g., to 101 classes)

*** 138. Becoming One With the Data (Part 2): Visualizing a Random Image ***
## **Lecture Summary: Visualizing and Exploring Image Data**

### **Recap**

* Dataset structure:

  * Around 75 training images and 25 testing images per class.
  * Each image class (e.g., steak, pizza, sushi) is placed in its respective folder:

    -------------------code----------------------
    train/steak/
    train/pizza/
    test/steak/
    test/pizza/
    -------------------code----------------------
  * This is the standard structure for image classification tasks.
  * When creating your own dataset, follow the same directory-based organization by class.

---

### **Objective**

Transform image files into tensors, but first, **explore and visualize** the data.

---

### **Plan to Visualize a Random Image**

1. **Get all image paths** using `pathlib.Path.glob()`.
2. **Pick a random image** path using `random.choice()`.
3. **Extract the image class name** (i.e., folder name) using `.parent.stem`.
4. **Open the image** using the Pillow library (`PIL.Image.open()`).
5. **Print image metadata** (class name, width, height).
6. **Display the image**.

---

### **Implementation Details**

#### 1. **Get All Image Paths**

-------------------code----------------------
from pathlib import Path

image_path_list = list(Path("data/images").glob("*/*/*.jpg"))
-------------------code----------------------

* `*/*/*.jpg`: Matches class folders in train/test sets and all `.jpg` images.
* Helps load all images across different categories and dataset splits.

#### 2. **Set Random Seed**

-------------------code----------------------
import random
random.seed(42)
-------------------code----------------------

* Ensures reproducibility by selecting the same random image.

#### 3. **Select a Random Image**

-------------------code----------------------
random_image_path = random.choice(image_path_list)
-------------------code----------------------

#### 4. **Get Image Class Name**

-------------------code----------------------
image_class = random_image_path.parent.stem
-------------------code----------------------

#### 5. **Open the Image**

-------------------code----------------------
from PIL import Image
img = Image.open(random_image_path)
-------------------code----------------------

* Pillow (`PIL`) is used to open and process images.

#### 6. **Print Metadata**

-------------------code----------------------
print(f"Path: {random_image_path}")
print(f"Class: {image_class}")
print(f"Width: {img.width}, Height: {img.height}")
-------------------code----------------------

#### 7. **Display the Image**

-------------------code----------------------
img.show()
-------------------code----------------------

---

### **Why Visualize Randomly?**

* Encourages better understanding of the dataset.
* Random selection helps uncover anomalies or edge cases.
* Important step before training to avoid surprises later.

---

### **Note on Data Visualization**

* For other domains (e.g., text, audio), similar methods exist:

  * Listen to random audio
  * Read random text
* Use domain-specific libraries for loading and displaying data.
