## 2. PyTorch Workflow Steps

1. **Prepare the data**
   - Load and preprocess your data.
   - Convert it to **tensors**, as tensors are the fundamental data structure in PyTorch.

2. **Build or select a model**
   - Either build your own model or use a **pretrained model**.

3. **Choose a loss function and optimizer**
   - The loss function measures the model’s performance.
   - The optimizer adjusts the model’s parameters to minimize the loss.

4. **Build a training loop**
   - Feed data into the model.
   - Calculate the loss and update weights.
   - Repeat this for several epochs (iterations).

5. **Evaluate the model**
   - Assess how well the model performs on new, unseen data.

6. **Experiment and improve**
   - Tweak your model, hyperparameters, or data preprocessing to enhance performance.

7. **Save and load the model**
   - Save your trained model for future use or deployment.
   - Reload the model when needed to avoid retraining from scratch.

# PyTorch Workflow: Step 1 - Data Preparation and Loading

## Introduction
- The first step in any machine learning workflow is **data preparation and loading**.
- Data in machine learning can come in many forms:
  - Structured tables (e.g., Excel spreadsheets)
  - Images
  - Videos
  - Audio (e.g., songs, podcasts)
  - DNA sequences

## The Core Idea of Machine Learning
Machine Learning (including Deep Learning) can be summarized in **two main steps**:
1. **Convert data into a numerical representation** (e.g., tensors).
2. **Build a model** to learn patterns in that numerical representation.

This is the foundational cycle of ML:
- Input data → Numerical encoding → Model learns patterns → Output predictions/actions

## Numerical Representation
- All data needs to be transformed into numbers (tensors in PyTorch).
- This process is called **encoding**.
- The choice of encoding depends on the type of data.
- After encoding, a neural network can be trained to learn features or patterns (often referred to as representations, features, or weights).

Examples of ML tasks after representation:
- Image classification (e.g., ramen vs spaghetti)
- Text classification (e.g., spam vs not spam)
- Audio recognition

## Summary of Two-Part ML Workflow
1. Convert raw data into a numerical representation (tensors).
2. Build (or use) a model to learn patterns from those tensors.

# Demonstration: Creating Synthetic Data with Known Parameters

To demonstrate this, the lecture uses **linear regression**.

### What is Linear Regression?
- A simple mathematical model to describe a straight-line relationship:
-------------------code----------------------
y = a + b*x
-------------------code----------------------
  - `a` is the intercept (value of `y` when `x = 0`)
  - `b` is the slope or gradient

Slope:
- The steepness of a line.
- Tells you how much y changes when x increases by 1.

Example: If slope = 2, then for every step right (x+1), y goes up by 2.

Intercept (y-intercept):
- Where the line crosses the y-axis (when x=0).
Example: If intercept = 3, the line passes through (0, 3).

Quick Comparison:
Slope (b): "How steep?"
Intercept (a): "Where does it start on the y-axis?"



This can also be written as:
-------------------code----------------------
y = weight * x + bias
-------------------code----------------------

In machine learning terminology:
- **Weight** = slope (`b`)
- **Bias** = intercept (`a`)
- These are also referred to as **parameters**, which are the values the model learns.

---

## Coding: Generating Known Data

1. Define known parameters:
-------------------code----------------------python
weight = 0.7
bias = 0.3
-------------------code----------------------

2. Create a range of values for `x`:
-------------------code----------------------python
import torch

start = 0
end = 1
step = 0.02
X = torch.arange(start, end, step).unsqueeze(1)
-------------------code----------------------

- `torch.arange()` creates evenly spaced values.
- `.unsqueeze(1)` adds a dimension (from shape `[N]` to `[N, 1]`) to prepare it as input for models.

3. Generate corresponding `y` values using the linear formula:
-------------------code----------------------python
Y = weight * X + bias
-------------------code----------------------

4. Check the data:
-------------------code----------------------python
print(X[:10])
print(Y[:10])
print(len(X), len(Y))  # Expected: 50 samples
-------------------code----------------------

---

## Purpose of This Step
- We are building a dataset with a known relationship between inputs and outputs.
- The goal later is to train a model to "rediscover" the original parameters (weight and bias) by learning from the data.

This is a controlled example to build intuition. In real-world scenarios, we typically do not know the true mapping between inputs and outputs — that’s what the model is supposed to learn.

---

## Note on Squeeze/Unsqueeze
- `.unsqueeze()` adds a dimension to the tensor, which is often necessary when feeding data into a model expecting inputs of shape `[batch_size, num_features]`.
- `.squeeze()` would remove such extra dimensions.

---

## Next Step

- Visualization helps with understanding how well the model learns over time.

*** 43. Splitting Our Data Into Training and Test Sets ***

### **Splitting Data in Machine Learning: Training, Validation, and Test Sets**

#### **Recap**
- Previously, we generated numbers on a page using the linear regression formula with known parameters.
- We're continuing to build on that foundation.

---

### **Why Splitting Data Is Important**
- One of the most critical concepts in machine learning is **splitting data into training and test sets**.
- This concept is essential for understanding how well a model generalizes to **unseen data**.
- Generalization: The ability of a model to perform well on data it hasn't seen before.

---

### **Analogy: University Exams**
Think of machine learning datasets like a university course:
- **Training Set**: Course materials – where the model learns.
- **Validation Set**: Practice exams – used to tune the model.
- **Test Set**: Final exam – evaluates generalization on unseen data.

---

### **Goal**
- The ultimate aim is to train a model that learns patterns from the training data and performs well on new, unseen data.

---

### **Standard Data Split**
- **Training Set**: 60% – 80% of total data.
- **Validation Set**: 10% – 20% (optional, used during model tuning).
- **Test Set**: 10% – 20% (always used to evaluate final performance).

---

### **Practical Example: Creating a Train-Test Split**
Assume we have 50 data points:

- We'll use an **80/20 split**, which is a common practice.
  - **Training Samples**: 40
  - **Testing Samples**: 10

#### **Code Summary (in PyTorch)**
-------------------code----------------------
# Determine split point
train_split = int(0.8 * len(X))  # 80% of the data

# Create training sets
X_train = X[:train_split]
Y_train = Y[:train_split]

# Create testing sets
X_test = X[train_split:]
Y_test = Y[train_split:]
-------------------code----------------------

---

### **Result Check**
-------------------code----------------------
len(X_train)  # 40
len(Y_train)  # 40
len(X_test)   # 10
len(Y_test)   # 10
-------------------code----------------------

- Training set: 40 features and labels
- Testing set: 10 features and labels

---

### **Alternative Methods**
- While this example uses manual indexing, more advanced methods include:
  - `sklearn.model_selection.train_test_split()` – adds randomness and shuffling.

---

### **Conclusion**
- You've now created proper **training and test sets**.
- Remember:
  - **Training set** = where learning happens.
  - **Test set** = where generalization is evaluated.
  - **Validation set** = optional, used during model selection and tuning.
- Proper splitting is one of the most important parts of any machine learning workflow.

## **What is `plt.figure()`?**

### Think of it like:
> A **blank canvas** where you can draw your plots.

### What it does:
- `plt.figure()` creates a **new figure window** — this is where your plots (like lines, bars, scatter plots) will be displayed.
- You can specify the **size** of the canvas using `figsize=(width, height)` in inches.

### Example:
-------------------code----------------------
plt.figure(figsize=(10, 7))
-------------------code----------------------
This creates a figure that’s 10 inches wide and 7 inches tall.

---

## **What is `plt.scatter()`?**

### Think of it like:
> A way to **plot individual data points** as **dots** on your figure.

### What it does:
- `plt.scatter(x, y)` takes two lists (or arrays):
  - `x`: the horizontal values
  - `y`: the vertical values
- It plots each pair `(x[i], y[i])` as a **dot** on the graph.

### Extra Options:
- `c`: color of the dots (e.g., `"b"` for blue, `"r"` for red)
- `s`: size of each dot
- `label`: label to show in the legend

### Example:
-------------------code----------------------
plt.scatter(X_train, y_train, c="b", s=4, label="Training data")
-------------------code----------------------
This will plot blue dots for each `(X_train[i], y_train[i])` pair.

---

### Putting it Together
-------------------code----------------------
plt.figure(figsize=(10, 7))           # Create a canvas
plt.scatter(x1, y1, c="b")            # Plot some blue dots
plt.scatter(x2, y2, c="g")            # Plot some green dots
plt.legend()
plt.show()                            # Display the figure
-------------------code----------------------

This shows a figure (canvas) with two sets of points (blue and green).
