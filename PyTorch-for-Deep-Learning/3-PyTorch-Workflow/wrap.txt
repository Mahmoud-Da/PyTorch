# Demonstration: Creating Synthetic Data with Known Parameters

To demonstrate this, the lecture uses **linear regression**.

### What is Linear Regression?
- A simple mathematical model to describe a straight-line relationship:
-------------------code----------------------
y = a + b*x
-------------------code----------------------
  - `a` is the intercept (value of `y` when `x = 0`)
  - `b` is the slope or gradient

Slope:
- The steepness of a line.
- Tells you how much y changes when x increases by 1.

Example: If slope = 2, then for every step right (x+1), y goes up by 2.

Intercept (y-intercept):
- Where the line crosses the y-axis (when x=0).
Example: If intercept = 3, the line passes through (0, 3).

Quick Comparison:
Slope (b): "How steep?"
Intercept (a): "Where does it start on the y-axis?"



This can also be written as:
-------------------code----------------------
y = weight * x + bias
-------------------code----------------------

In machine learning terminology:
- **Weight** = slope (`b`)
- **Bias** = intercept (`a`)
- These are also referred to as **parameters**, which are the values the model learns.

---

## **1. Gradient Descent**

### **What it is:**
Gradient Descent is an **optimization algorithm** used to minimize a **loss function** by adjusting the model's parameters (like weights and biases).

### **Why it’s important:**
The goal of training a machine learning model is to make accurate predictions. To do that, the model needs to **minimize the error** (difference between predicted and actual values). Gradient descent helps achieve that.

### **How it works (intuition):**
Think of it like trying to find the **lowest point in a valley (the minimum of a function)**:

1. Start at a random point (random weights).
2. Look around to see in which direction the slope goes down (compute the gradient).
3. Take a small step downhill (update the weights).
4. Repeat until you’re at the bottom (minimum loss).

### **Mathematically:**
If `w` is a weight and `L(w)` is the loss function:

-------------------code----------------------
w_new = w_old - learning_rate * gradient_of_L_with_respect_to_w
-------------------code----------------------

The **learning rate** controls how big your steps are.

---

## **2. Backpropagation**

### **What it is:**
Backpropagation is the **algorithm** used to **compute the gradients** needed for gradient descent.

### **Why it’s important:**
To know how to adjust each weight, the model needs to understand how changing a weight affects the loss. Backpropagation does exactly that by using **the chain rule of calculus**.

### **How it works (in steps):**
1. Perform a **forward pass**: Compute the output of the network with current weights.
2. Compute the **loss**: Measure how far off the prediction is from the actual value.
3. **Backpropagate**: Go backwards through the network to compute the gradient (how much each weight contributed to the loss).
4. Use **gradient descent** to update weights using those gradients.

---

## **Quick Analogy:**
Imagine you're blindfolded on a hilly terrain trying to reach the lowest point:

- **Gradient Descent** is how you figure out which direction to move to go downhill.
- **Backpropagation** is how your brain processes feedback from your steps (how steep the hill is in each direction) so you can adjust your next move.

#  Loss Function vs Optimizer in PyTorch

## Recap
In the last session, we observed that our model performs poorly. Ideally, the predicted values (red dots) should align with the actual data (green dots), but they don't. This is expected since our model is initialized with **random parameters**.

### Note:
- You **don’t have to** initialize your model with random values.
- You could initialize weights and biases as **zero**, or even use parameters from another model (a concept known as **transfer learning**, which we’ll explore later).

---

## The Goal of Training
The purpose of training is to guide a model from **unknown parameters** (e.g., random) to **known parameters** that better represent the underlying data.

### Our Objective:
- Improve from a **poor representation** to a **better representation**.
- Example: Our red dots (predictions) should match the green dots (real data).

---

## Measuring Model Performance: The Loss Function

To measure **how wrong** the model's predictions are compared to actual data, we use a **loss function**.

### What is a Loss Function?
- A function that **quantifies** the difference between model predictions and actual values.
- Lower loss = better model.
- It helps us determine **how far off** the red dots are from the green dots.

#### Common Loss Functions in PyTorch:
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- Cross Entropy Loss (for classification)

> Note: In PyTorch documentation, a loss function may also be called a:
> - **Cost function**
> - **Criterion**

Although there may be slight formal differences in other fields, we’ll treat these as interchangeable in this context.

### Example:
To measure the distance between predicted and actual points:
1. Calculate differences for each point.
2. Take the average of these distances.
3. This process is essentially **Mean Absolute Error (MAE)**.

---

## Training Requirements

### 1. **Loss Function**
- Measures model error.
- Guides the optimizer on how to adjust the model.

### 2. **Optimizer**
- Adjusts model parameters to reduce the loss.
- Takes the **loss value**, calculates **gradients**, and updates **weights and biases** accordingly.

#### Example in PyTorch:
-------------------code----------------------
loss = loss_fn(predictions, targets)
loss.backward()
optimizer.step()
-------------------code----------------------

### Model Parameters in PyTorch:
- `model.parameters()` returns a generator of parameters.
- `model.state_dict()` shows named parameters (e.g., `weight`, `bias`).

---

## Summary: Formal Definitions

| Term         | Description |
|--------------|-------------|
| **Loss Function** | Measures how wrong model predictions are. Lower is better. |
| **Optimizer**     | Uses the loss to adjust the model’s parameters (e.g., weight, bias) to reduce future loss. |

### Final Thoughts:
The concepts of **loss functions** and **optimizers** apply to:
- Simple models (e.g., predicting a line).
- Complex models (e.g., deep neural networks).
- Domains like vision, NLP, and more.

## **Loss Function**

### **Purpose:**  
Measures **how wrong** the model’s predictions are.

### **What it does:**
- Takes the model's predictions and the true values (labels), and calculates a **single number** representing the difference.
- This number is called the **loss**.
- The goal during training is to **minimize** this loss.

### **Examples:**
- **Mean Squared Error (MSE):** for regression problems
- **Cross Entropy Loss:** for classification problems

### **Example Code:**
-------------------code----------------------
loss_fn = nn.MSELoss()
loss = loss_fn(y_preds, y_true)
-------------------code----------------------

---

## **Optimizer**

### **Purpose:**  
**Updates the model's parameters** to reduce the loss.

### **What it does:**
- Looks at the gradients of the loss (calculated by backpropagation).
- Applies a **mathematical algorithm** to adjust the model's parameters (weights and biases).
- The optimizer decides *how much* and *in what direction* to change each parameter to improve performance.

### **Examples:**
- **SGD (Stochastic Gradient Descent)**
- **Adam** (adaptive learning rate method)

### **Example Code:**
-------------------code----------------------
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
optimizer.zero_grad()      # Reset gradients
loss.backward()            # Backpropagate
optimizer.step()           # Update parameters
-------------------code----------------------

---

## How They Work Together in Training:
1. Model makes predictions.
2. **Loss function** compares predictions to actual values.
3. **Loss** is computed.
4. `loss.backward()` calculates gradients.
5. **Optimizer** updates parameters using those gradients.
6. Repeat for many iterations to improve accuracy.

---

### Summary:
| Component     | Role                                      |
|---------------|-------------------------------------------|
| Loss Function | Tells how bad the predictions are         |
| Optimizer     | Adjusts model to make better predictions  |

## **Lecture Summary: Training a Machine Learning Model in PyTorch**

### **1. Training Concept Overview**
- Training transforms random model parameters into values that better represent the data.
- This is achieved by minimizing a **loss function** using an **optimizer**.
- The goal is to make the model's predictions as close as possible to the actual outputs.

---

### **2. Loss Function**
- **Definition**: Measures how wrong the model’s predictions are.
- **Goal**: Lower the loss to improve model performance.
- **PyTorch Implementation**: Many built-in loss functions available via `torch.nn`.
- **Types Discussed**:
  - **L1 Loss (Mean Absolute Error)**:
    - Calculates the average of absolute differences between predictions and actual values.
    - Suitable for **regression problems**.
  - **MSE Loss (Mean Squared Error)**:
    - Also used for regression.
  - **Cross Entropy Loss**:
    - Used for **classification problems**.
- **PyTorch Code Example**:
-------------------code----------------------
import torch.nn as nn
loss_fn = nn.L1Loss()
-------------------code----------------------

---

### **3. Optimizer**
- **Definition**: Algorithm that adjusts model parameters to reduce the loss.
- **PyTorch Location**: `torch.optim`
- **Popular Optimizers**:
  - **SGD (Stochastic Gradient Descent)**:
    - Updates model parameters by taking random steps to minimize the loss.
    - Basic and widely used.
  - **Adam**:
    - Adaptive learning rate and momentum-based optimization.

- **PyTorch Code Example (SGD)**:
-------------------code----------------------
import torch.optim as optim
optimizer = optim.SGD(params=model.parameters(), lr=0.01)
-------------------code----------------------

---

### **4. Important Concepts**
- **Gradient Descent**:
  - Algorithm to iteratively minimize the loss by adjusting weights.
  - Stochastic gradient descent adds randomness to updates.
- **Backpropagation**:
  - Computes gradients used by the optimizer to adjust parameters.

---

### **5. Hyperparameters**
- **Definition**: Values set by the data scientist before training starts.
- **Key Hyperparameter**:
  - **Learning Rate (`lr`)**:
    - Controls how much to change model parameters during each update.
    - Small `lr` = small updates (slow learning).
    - Large `lr` = big updates (risk of overshooting optimum).

- **Typical Learning Rate Values**:
  - `0.1`, `0.01`, `0.001`

### **6. Summary**
- **Loss function** = Measures prediction error.
- **Optimizer** = Adjusts parameters to reduce loss.
- Loss function and optimizer work together in the training loop.
